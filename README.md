# TJ Jude Agent Onboarding

Premium onboarding experience for TJ Jude — dancer, host, choreographer.

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion + GSAP
- Zustand
- lottie-react
- Howler.js
- Supabase
- shadcn/ui
- Lucide React

## Features

- Floating glassmorphism card with parallax + ambient glow
- 3D card flip transition (600ms, PRD exact easing)
- 9-question conversational flow with 5 UI types
- Aurora gradient background with particles
- Lottie animations + sound design
- Auto-save to Supabase
- Airtable auto-generation
- Telegram notification to Shapiro
- Admin dashboard

## Development

```bash
npm install
npm run dev
```

## Deploy

```bash
vercel
```

## Environment Variables

Copy `.env.example` to `.env.local` and fill in your keys.
